# Tarapoto Tours

Frontend estático listo para ejecutar con XAMPP.

## Cómo abrirlo

1. Copia la carpeta en `htdocs`.
2. Enciende Apache en XAMPP.
3. Abre:

```text
http://localhost/turitours/
```

El `index.html` raíz redirige a `public/index.html`, que es la versión principal del sitio.

## Estructura

- `public/` — HTML, CSS y JavaScript vanilla.
- `app/` — restos del proyecto Next.js (archivados). Ver `archive/app-backup/` y `archive/config-next/`.
- `node_modules/` — solo para desarrollo con Node/npm.
